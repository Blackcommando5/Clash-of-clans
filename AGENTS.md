# Project working instructions

- Update `BEGINNER_GUIDE.md` with every project development update, as requested by the user. Keep the playable feature summary, beginner walkthrough, relevant source links, validation evidence, and known limitations accurate. Preserve useful foundational lessons but clearly label historical examples.
- Keep changes in meaningful, reviewable commits. Include Unity `.meta` files with their assets. Do not commit generated Unity caches, isolated validation projects, local saves, credentials, or build outputs.
